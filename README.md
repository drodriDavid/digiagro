# DIGIAGRO

Web de DIGIAGRO, la Unidad de Transformación Digital e Inteligencia Artificial del INUO (Universidad de Jaén).

Sitio estático para GitHub Pages, sin compilación.

- `contenido.js`: proyectos, publicaciones y personas. Es lo que más se actualiza.
- `index.html`: textos de la unidad, líneas, medios y herramientas.
- `olivar.js`: visor WebGL de la nube real de la portada (`assets/nube/`, sin georreferencia).
- `styles.css`: estilos, solo modo claro.

Para verla en local: `python -m http.server` en esta carpeta.
